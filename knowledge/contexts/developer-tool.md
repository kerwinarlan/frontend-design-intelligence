# Context Guide: Developer Tools & CLI Web Interfaces

Developer tools, API management dashboards, and CLI web interfaces cater to software engineers and technical operators.

## Core Design Principles

1. **Terminal & Code Integration**: Embed syntax-highlighted code blocks, copy-to-clipboard micro-interactions, and command outputs.
2. **Keyboard Ergonomics**: Support full keyboard navigation (`⌘K` command palette, `/` search focus, Esc dismiss).
3. **Monospace Typography**: Pair clean sans-serif headers with crisp monospace body code (Geist Mono, JetBrains Mono, Fira Code).
4. **Dark Mode First**: Default to dark zinc tones (`#09090B`) preferred by developers.

## Inappropriate Patterns
* Fluffy marketing prose or non-technical jargon.
* Hiding API keys or configuration options behind confusing visual metaphors.
