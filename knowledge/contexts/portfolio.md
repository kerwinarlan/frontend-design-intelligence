# Context Guide: Developer Portfolios & Technical Case Studies

Developer portfolios showcase an engineer's craftsmanship, architectural depth, and problem-solving process to technical leaders, recruiters, founders, and clients.

## Core Design Principles

1. **Engineering Narrative**: Explain the problem, architecture, tradeoffs, code snippets, and measured metrics.
2. **Stack Visibility**: Display explicit tech stack badges (e.g. Next.js 15, Rust, WASM, Tailwind, PostgreSQL) in the hero section.
3. **Live Interactive Demos**: Embed recorded device mockups, interactive code sandboxes, or direct live links.
4. **Measured Proof**: Present exact performance figures (e.g., "-42% bundle size", "P99 14ms latency", "100/100 Lighthouse score").

## Inappropriate Patterns
* Fake testimonials, fake client logos, or fabricated star ratings on personal projects.
* Generic slogans ("Revolutionizing software with AI").
* Low-contrast glassmorphism or purple/pink ambient blur orbs.
